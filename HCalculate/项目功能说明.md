# HCalculate 项目功能说明

## 1. 项目简介

HCalculate 是基于 STM32F103C8T6 的触摸按键计算器，使用 LCD1602 显示输入和结果，并通过 USB CDC 虚拟串口接收电脑发送的文本和统计命令。

项目基于招新 example 工程，复用其计算器应用、表达式引擎、LCD 驱动、触摸读取、滤波和识别静态库，在此基础上扩展 USB 文本接收、STAT 模式及统计计算功能。

本文根据当前工程源码和库接口整理。下文演示数值为预期结果，不代表已经逐项完成开发板实测。

## 2. 功能总览

| 功能类别 | 主要内容 | 使用入口 |
| --- | --- | --- |
| 触摸输入 | 数字、运算符、括号、输入编辑及 SHIFT 功能 | 实体触摸按键 |
| 基本计算 | 加、减、乘、除、小数及 AC 清空 | COMP 模式 |
| 表达式与函数 | 括号、优先级、乘方、开方、三角函数、对数 | COMP 模式及 SHIFT 功能键 |
| 角度设置 | DEG 角度制、RAD 弧度制 | MODE → ANGLE UNIT |
| 复数计算 | 复数表达式求值；串口结果按实部、虚部分开显示 | CMPLX 模式或 C / COMPLEX 命令 |
| USB 文本显示 | 接收可打印字符、显示输入、支持退格和换行处理 | USB 虚拟串口 |
| 线性拟合 | 最小二乘拟合直线，计算斜率、截距和 R² | STAT 模式中的 STAT 命令 |
| 其他统计 | 描述统计、相关分析、线性预测、二次拟合、Z 分数分析 | STAT 模式中的对应串口命令 |

## 3. 基本计算与输入编辑

### 3.1 操作方式

1. 按 `MODE`，通过上下键选择 `COMP`，按 `OK` 确认。
2. 通过数字和运算符按键输入表达式。
3. 按 `EXE` 计算。
4. 按 `DEL` 删除输入，按 `AC` 清空。

### 3.2 演示用例

每次演示前先按 `AC`，输入完成后按 `EXE`。

| 输入表达式 | 预期结果 | 展示内容 |
| --- | --- | --- |
| `12+8` | `20` | 加法 |
| `9-15` | `-6` | 减法和负数结果 |
| `6*7` | `42` | 乘法 |
| `8/4` | `2` | 除法 |
| `1.5+2.25` | `3.75` | 小数运算 |
| `2+3*4` | `14` | 乘除优先于加减 |
| `(2+3)*4` | `20` | 括号改变计算顺序 |

输入 `123` 后按 `DEL`，可演示删除；再按 `AC`，可演示清空。计算引擎提供语法错误、定义域错误和除零错误状态，演示时可检查错误提示后是否能清空并继续计算。

## 4. 函数与角度设置

### 4.1 科学计算

原计算器库提供三角函数、开方、乘方、对数等计算功能，并支持常数和上一次计算结果的使用。

`SHIFT` 的操作方式为先按一下 `SHIFT`，再按相应功能键。

| 功能 | 按键步骤 | 预期结果 |
| --- | --- | --- |
| 2 的 3 次方 | `2 → SHIFT → × → 3 → EXE` | `8` |
| 9 的平方根 | `SHIFT → ÷ → 9 → ) → EXE` | `3` |
| 100 的常用对数 | `SHIFT → 5 → 100 → ) → EXE` | `2` |
| sin(30°) | `SHIFT → 1 → 30 → ) → EXE` | 约 `0.5` |
| cos(60°) | `SHIFT → 2 → 60 → ) → EXE` | 约 `0.5` |
| tan(45°) | `SHIFT → 3 → 45 → ) → EXE` | 约 `1` |

三角函数示例使用 `DEG`。函数键输入函数及左括号，示例中需要补右括号。

### 4.2 ANGLE UNIT

通过 `MODE → ANGLE UNIT` 进入角度设置，选择并确认：

- `DEG`：角度制，一周为 360°。
- `RAD`：弧度制，一周为 2π。

设置后返回计算界面。例如 `sin(30)` 在 DEG 下约为 0.5，在 RAD 下表示 30 弧度的正弦，含义不同。

## 5. 复数计算

通过 `MODE → CMPLX` 进入原计算器的复数计算模式。

串口也提供独立的复数求值入口：

```text
C 表达式
COMPLEX 表达式
```

这两个前缀调用同一个表达式引擎，启用复数计算。成功时 LCD 第一行显示 `Re=` 实部，第二行显示 `Im=` 虚部；上一次成功的串口复数结果保存供后续命令使用。

当前串口复数入口固定以 DEG 调用计算引擎，不跟随实体菜单中的 ANGLE UNIT 设置。表达式记号遵循 example 计算引擎的语法。

## 6. USB 串口与文本显示

### 6.1 连接方法

1. 使用支持数据传输的 USB 线连接开发板和电脑。
2. 在 Tera Term 等串口终端中选择开发板枚举出的 USB 虚拟串口。
3. 终端使用 ASCII 英文字符输入，回车发送设置为 `CR` 或 `CR+LF`。
4. 如需逐字显示，使用直接键入即发送的终端方式；只在点击发送后才发出整行数据的工具，无法让开发板提前显示尚未收到的字符。

### 6.2 输入显示规则

- 程序接收 ASCII 可打印字符，并由任务处理和刷新 LCD。
- LCD 第一行显示当前输入；超过 16 个字符时显示末尾 16 个字符。
- LCD 第二行显示 `USB RX` 和当前输入长度。
- 支持 Backspace 和 Delete 对应的退格字符。
- 普通文本换行时尝试以 `RX:` 前缀回传。
- 启动后的首次接收数据时尝试发送 `HCalculate READY`，并非一上电就保证终端收到。

串口接收不依赖进入 STAT；统计计算命令则需要先进入 STAT 才能执行。终端的“本地回显”只影响电脑是否显示键入内容，不证明开发板已经收到数据。

## 7. STAT 统计模式

### 7.1 进入与退出

进入方式：

1. 按 `MODE` 打开模式选择菜单。
2. 使用 `↑/↓` 选择 `> STAT`。从初始的 ANGLE UNIT 项开始，按 `↓` 三次到达 STAT。
3. 按 `OK` 或 `EXE` 确认。
4. LCD 显示 `STAT MODE / SERIAL INPUT`。
5. 通过串口输入完整命令，按电脑键盘的回车提交。

进入 STAT 会清空此前的串口命令文本。STAT 中的统计数据通过串口输入，不使用实体数字键逐个录入。

退出时按 `MODE` 返回模式选择菜单，再选择 `COMP`、`CMPLX` 或 `ANGLE UNIT`。当前扩展代码从 CMPLX 项恢复菜单位置，以屏幕上的实际选中项为准。

### 7.2 命令格式

数字之间使用英文逗号 `,`，不同数据组之间使用英文分号 `;`。每条命令输入完成后按回车。

| 命令 | 格式 | 输出内容 |
| --- | --- | --- |
| `STAT` | `STAT x1,x2,...;y1,y2,...` | 线性拟合式、R²、数据对数 |
| `DESC` | `DESC v1,v2,...` | 均值、数量、总体标准差、最小值 |
| `CORR` | `CORR x1,x2,...;y1,y2,...` | Pearson 相关系数及线性拟合 R² |
| `PRED` | `PRED x1,x2,...;y1,y2,...;xp` | 在 xp 处的线性预测值及斜率 |
| `QUAD` | `QUAD x1,x2,...;y1,y2,...` | 二次拟合系数 a、b、c 及当前实现的拟合指标 |
| `ZSCORE` | `ZSCORE v1,v2,...` | 最大绝对 Z 分数及对应数据序号 |

### 7.3 线性最小二乘拟合

输入示例：

```text
STAT 1,2,3;2,4,6
```

拟合模型为 `y = ax + b`，其中：

```text
a = Σ[(xi-x̄)(yi-ȳ)] / Σ[(xi-x̄)²]
b = ȳ - a*x̄
R² = 1 - Σ[yi-(a*xi+b)]² / Σ[(yi-ȳ)²]
```

该示例预期得到斜率 2、截距 0、R² 为 1。屏幕以 `R2` 表示 R²，并显示数据对数 `n`。

### 7.4 描述统计

```text
DESC 1,2,3
```

预期均值为 2、数量为 3、总体标准差约为 0.816、最小值为 1。屏幕字段为 `M`、`N`、`SD`、`MIN`。

当前标准差按 `sqrt(Σ(vi-均值)² / n)` 计算，分母是 n，不是样本标准差使用的 n-1；当前界面未输出最大值、中位数或众数。

### 7.5 相关分析

```text
CORR 1,2,3;2,4,6
```

预期 Pearson 相关系数 r 为 1，线性拟合 R² 为 1。r 描述线性相关方向与强度，不代表因果关系。

### 7.6 线性预测

```text
PRED 1,2,3;2,4,6;4
```

前两组是拟合数据，最后一个数字是待预测的 x。预期输出 `YHAT=8.0`，斜率 a 为 2。

### 7.7 二次拟合

```text
QUAD 1,2,3;1,4,9
```

拟合模型为 `y = a*x² + b*x + c`。使用正规方程和带主元选择的高斯消元求系数；该示例预期 a 约为 1，b、c 约为 0。

二次拟合应至少提供 3 个不同的 x。若方程组奇异，显示 `SINGULAR`。

当前 QUAD 的 `R2` 字段按 `1-SSE/Σ(yi²)` 计算，没有使用中心化的总平方和，因此不能直接当作标准定义的 R²。标准 R² 的演示优先使用 STAT 线性拟合功能。

### 7.8 Z 分数分析

```text
ZSCORE 1,2,10
```

使用总体标准差计算 `z = (vi-均值)/SD`，输出最大的 `|z|`，以及从 1 开始的数据序号。该示例预期最大绝对 Z 分数约为 1.407，序号为 3。

本功能寻找相对均值偏离最大的数据点，没有设置异常值阈值，不直接给出“异常/正常”分类。

## 8. 输入限制与错误提示

- 每组数组最多 16 个数据；x、y 必须等长。
- 线性拟合、相关分析和线性预测至少需要 2 对数据。
- 串口命令缓冲区最多保存 63 个字符，因此实际可输入的数据量还受到整行命令长度限制。超过长度会丢弃行首字符，应使用较短命令。
- 统计结果按单精度浮点计算，当前格式化通常保留最多 3 位小数，不属于任意精度计算。
- LCD 每行只有 16 个字符；串口结果回传复用同样两行，因此较长结果可能被截断，串口不会额外提供完整长结果。
- 未进入 STAT 就发送统计命令，返回 `STAT LOCKED / PRESS MODE`。
- 格式错误、两组长度不同或数据不足，返回对应的 `ERROR` 提示。
- 线性拟合遇到 x 方差过小，返回 `X VARIANCE 0`。
- Z 分数计算遇到标准差过小，返回 `SD ZERO`。
- 对常数 y，相关系数数学上没有定义；当前 CORR 的退化处理会输出 r=0，不应据此判断为“没有相关性”。

## 9. 软件结构与实现来源

| 文件或目录 | 职责 |
| --- | --- |
| `Core/Src/main.c` | 硬件与 USB 初始化、创建任务、启动 FreeRTOS |
| `USB_DEVICE/App/usbd_cdc_if.c` | USB CDC 接收回调，将字节加入缓冲区 |
| `App/serial_text.c` | 环形缓冲消费、文本编辑、LCD 输入显示、命令触发与结果回传 |
| `App/hcalculate_mode.c` | 原菜单外围的 STAT 扩展、按键处理与部分 LCD 写入控制 |
| `App/hcalculate_math.c` | 统计命令解析、统计算法、数值格式化及复数命令入口 |
| `lib/` | example 提供的六个预编译静态库 |
| `CMakeLists.txt`、`cmake/` | 源文件、依赖、编译器和链接参数配置 |

普通计算、触摸读取、滤波与识别、表达式解析等核心功能复用 example 静态库；新增源代码实现串口交互及统计扩展。LCD 和触摸接口通过链接器 `--wrap` 增加外围处理，没有重新编写库内部的表达式解析器。

## 10. 建议的演示顺序

1. 展示正常启动和实体数字键输入。
2. 在 COMP 中演示四则运算、括号优先级、DEL 和 AC。
3. 选择 DEG，演示 sin(30°)、开方和乘方。
4. 展示 CMPLX 模式入口及复数计算。
5. 在串口输入短文本，观察 LCD 的输入和字符计数。
6. 进入 STAT，逐字输入 `STAT 1,2,3;2,4,6`，展示回车前的输入和回车后的结果。
7. 演示 DESC、CORR、PRED、QUAD 和 ZSCORE 命令。
8. 按 MODE 选择 COMP，确认返回普通计算。

正式演示前，应在实际开发板上逐项检查以上操作，并将真实结果记录在项目报告或演示视频中。
